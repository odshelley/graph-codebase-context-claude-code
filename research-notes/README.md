# Research notes

These seven files are the raw outputs of the parallel research agents that fed the main report, produced on 1 October 2026. They are preserved as supporting evidence: every URL in them was fetched on that date, GitHub star counts and licences come from the GitHub API, and package versions from PyPI. Each file flags claims it could not confirm against a primary page as `UNVERIFIED`; treat those as leads, not findings. The main report in the repository root is the edited, cross-checked synthesis and takes precedence where the two differ.

| File | Scope |
| --- | --- |
| `01-claude-code-native-context-features.md` | What Claude Code offers natively for context management, from the official documentation |
| `02-academic-evidence-code-graphs.md` | Literature review of graph-based repository representations for coding agents, with exact benchmark numbers |
| `03-open-source-code-graph-tools.md` | Survey of open-source code-graph tools and MCP servers usable with Claude Code |
| `04-commercial-code-context-platforms.md` | Survey of commercial code-context platforms and how they integrate with Claude Code |
| `05-graph-database-ecosystem-neo4j.md` | Neo4j and other graph-database assets for a code graph, including text-to-Cypher reliability evidence |
| `06-enterprise-security-governance.md` | MCP threat model, Neo4j controls, data residency, access control, scale, governance |
| `07-docs-to-code-linking-case-studies.md` | Linking documentation graphs to code graphs, and enterprise case studies at scale |
